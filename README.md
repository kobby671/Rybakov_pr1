# Практическая работа №1

## Тема
HTML и базовая CSS-разметка. Семантическая структура страницы.

## Описание проекта
Разработан адаптивный информационный сайт, посвящённый технологиям разработки программного обеспечения.

Сайт содержит:
- Навигационное меню.
- Раздел с описанием курса.
- Шесть информационных карточек.
- Таблицу направлений.
- Форму регистрации.

## Используемые технологии
- HTML5
- CSS3
- Flexbox
- Media Queries

## Исходные данные
В проекте используются файлы из папки `dataset`:
- `content.csv` — данные для карточек и таблицы.
- `navigation.json` — пункты навигационного меню.
- `assets/cover.svg` — изображение страницы.
- `assets/logo.svg` — логотип из исходных материалов.

## Запуск проекта
1. Скачать или клонировать репозиторий.
2. Открыть папку проекта.
3. Запустить файл `index.html` в браузере.

## Адаптивность
Сайт адаптирован для мобильных устройств с помощью Flexbox и медиазапросов CSS.
